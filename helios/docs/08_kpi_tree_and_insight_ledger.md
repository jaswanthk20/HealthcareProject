# Indicators and evidence ledger

## Governed indicators

1. Has a regular healthcare provider.
2. Diabetes.
3. High blood pressure.
4. Perceived mental health, fair or poor.
5. Anxiety disorder.
6. Mood disorder.
7. Adjusted self-reported body mass index, obese.
8. Current smoker, daily or occasional.

Each percentage is a published source estimate for a specific year, geography, age and sex. Confidence intervals use the publisher's bootstrap estimates. No population denominators or fictional patient counts are manufactured.

## Evidence rules

An observation must identify the indicator, population, reference year, estimate, confidence interval, quality flag and source. Differences remain descriptive unless supported by a separate appropriate analysis. A healthcare-provider trend spanning 2024 must carry the source question-change warning.

Prior prototype findings and drug-launch decisions were retired because this source cannot substantiate them. The dashboard provides the current evidence table; it does not retain unsupported figures as historical real-world findings.
